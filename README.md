### 1. PCI DSS v4.0 — Network Segmentation Review
📁 [View Project](./PCI-DSS-Project/)

Assessed all 12 PCI DSS requirements for FinSecure — 
a fictional fintech startup processing payments for 
100,000 customers.

Key decisions made:
